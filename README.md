# skinulis — «Скинулись»

> Бот для общих сборов в телеграм-чате. Кто скинулся → ✅, кто тянул до последнего → 💀.

**Живой бот:** [сюда вставь ссылку после установки на сервер]

---

## Зачем

Скинуться на подарок, на пиццу, на такси — органика любого чата. А учёт всегда мёртв: кто-то
«отправил» (не отправил), кто-то забыл, кто-то потом полгода сходит с ума, кто отдал сколько.

skinulis делает ровно одну вещь — держит честный счёт и называется это вслух:

- `/skor Подарок Лене по 300 до 28.12` — сбор создан, карточку уже в чате
- участники открывают мини-аппу (кнопка прямо из карточки) и жмут «Я скинулся ✅»
- сумма, дедлайн, реквизиты организатора — всё перед глазами
- перед дедлайном бот тормошит должников лично
- после закрытия сбор автокорежится: бот честно называет тех, кто тянул резину

Деньги **не идут через бот**. Переводы между людьми напрямую (СБП/карта), приложение ведёт
счёт и подтверждения. Поэтому тут нет скам-элементов и нет лишних разрешений.

## Запуск у себя

Python 3.9+, зависимостей ноль — тащить пакеты не нужно.

```bash
git clone https://github.com/Dismirkils/skinulis.git
cd skinulis
BOT_TOKEN=токен_от_botfather python3 bot.py
```

Веб-часть (мини-аппа + API) поднимется на `http://localhost:3001/app`.
Порт 3001 выбран не просто так: 3000 обычно занят (у меня там музыкальный сайт).

Без `BOT_TOKEN` запускается веб-часть в демо-режиме — можно сразу открыть
в браузере и посмотреть.

## Настройка в @BotFather

1. `/newbot` → имя → юзернейм → получить токен
2. Токен в `BOT_TOKEN` и запустить (см. выше)
3. Мини-аппа требует публичный HTTPS (Телеграм сам не откроет localhost):

   - самый простой путь — VPS + Caddy (ниже)
   - для проверки с телефона можно кинуть туннель: `cloudflared tunnel --url http://localhost:3001`
     и в BotFather `/setmenubutton` → `https://что-то.trycloudflare.com/app`

Команды, которые понимает бот (`/setcommands`, вставляй по вкусу):

```
skor  - создать сбор: /skor Название по 300 до 28.12
list  - активные сборы в чате
close - закрыть свой последний сбор
start - мои сборы
```

## Прод (VPS, systemd, Caddy)

После первого запуска — работает без обслуживания. systemd поднимает, Caddy выдаёт HTTPS.

```bash
# 1. заливаем
git clone https://github.com/Dismirkils/skinulis.git ~/skinulis && cd ~/skinulis

# 2. сервис, чтобы жило вечно
cat > /etc/systemd/system/skinulis.service <<'EOF'
[Unit]
Description=skinulis bot
After=network.target

[Service]
WorkingDirectory=/root/skinulis
Environment=BOT_TOKEN=тут_токен
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now skinulis

# 3. HTTPS для мини-аппы (домен заранее настроил A-запись на IP)
echo "домен.ру {
    reverse_proxy localhost:3001
}" > /etc/caddy/Caddyfile
systemctl reload caddy

# 4. BotFather: /setmenubutton → https://домен.ру/app
```

## Что где лежит

```
bot.py           весь бэкенд одним куском: Bot API (polling), HTTP-сервер, мини-аппа API,
                 напоминания, хранение. Намеренно без воркера и микрофреймворков —
                 разобраться можно за один вечер.
public/          фронт мини-аппы: index.html + style.css + app.js, ванильный js
data/state.json  всё состояние (юзеры, сборы, платежи, напоминания). Бэкап — просто
                 скопировать файл. Начать заново — снести.
```

## Ограничения, о которых стоит знать

- бот не видит **весь** состав чата (так работает Telegram) — в списке появляются
  те, кто открыл аппу или уже скинулся. Кто-то не открыл — его дожидает карточка в чате
- дедлайны считаются по часам сервера (МСК/UTC — где поставил, там и живёт)
- один платёж на юзера в рамках одного сбора (перезаписывает), нечестные манипуляции
  через два аккаунта решаются общением, а не кодом :)
- подпись(web-app initData) проверяется честно через HMAC, токен токена не подходит
