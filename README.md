# Скинулись 💸

Бот + мини-аппа для общих сборов в Telegram-чатах: день рождения, пицца, цветы уходящему, поездка.
Один файл `bot.py`, чистый Python **3.9+**, никаких зависимостей и баз данных.

Механика: в чате создаёшь сбор командой `/skor`, бот постит карточку, все скидываются
через мини-аппу и жмут «Я скинулся». Бот назойливо напоминает должникам, а в конце
честно показывает, кто слился 💀. Деньги перекидываются напрямую (СБП/карта) — бот только
ведёт учёт и не трогает чужие деньги.

## Быстрый старт

```bash
# 1. Создай бота: @BotFather → /newbot → скопируй токен
BOT_TOKEN=123:abc python3 bot.py
```

Порт по умолчанию — **3001** (3000 обычно занят музыкальным сайтом).
Без `BOT_TOKEN` запускается веб-часть — браузером открывай `http://localhost:3001/app`,
там демо-данные для наглядности.

## В чате группы

```
/skor Подарок Лене по 300 до 28.12 анонимно
```

- `по 300` — фиксированная сумма с каждого (можно `$`, `€`)
- `на 5000` — общая цель («скинулись 3200 из 5000»)
- `до 28.12 20:00` — дедлайн (год не обязательно, время не обязательно)
- `анонимно` — скрыть имена и суммы, показать только счётчики
- ничего не указал — «кто сколько хочет»

Остальное: `/list` — активные сборы чата, `/close` — закрыть свой последний,
`/start` — свои сборы, `/help`.

## Мини-аппа

Там живут: кто скинулся/не скинулся, реквизиты с кнопкой «копировать», кнопка
«Я скинулся ✅», органайзер-панель (реквизиты, завершение сбора), напоминания.
Открывается по кнопке «Скинуться» прямо из карточки в чате.

**Этап подключения через @BotFather:**

1. `/newbot` — создать бота, получить токен
2. Скормить `bot.py` токен — механика чата заработает сразу (long polling, наружу ничего не нужно)
3. Для мини-аппы нужен **публичный HTTPS-адрес** (Telegram\Config App страница откроет только https):
   поставь на VPS (инструкция ниже) и пришли BotFather:
   - `/newapp` → URL вида `https://твой-сайт/app` → так мини-аппа получит свой deep-link
   - или `/setmenubutton` → тот же URL (кнопка «меню» у бота)

## Настройки (переменные окружения)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `BOT_TOKEN` | нет | токен от @BotFather; без него — только веб (демо) |
| `PORT` | `3001` | порт веб-сервера |
| `BOT_USERNAME` | из getMe | использовать, если бот в другом экземпляре |

`DEV_MODE` отдельно не ставится: включается автоматически, когда нет токена —
создаёт демо-сбор и позволяет вносить изменения (тесты API без подписи Telegram).

## Где хранится всё

Всё в `data/state.json` рядом с ботом: пользователи, сборы, платежи, пометки «уже
напоминали». Файл перезаписывается атомарно (tmp + rename) — сенсор данных минимальный.
Чтобы начать заново — снеси `data/state.json`.

## Дожиматель (встроенный)

- **за 24ч до дедлайна** — личное сообщение каждому неплатившему
- **в момент дедлайна** — финальный пинок («успеешь до финального подсчёта…»)
- **через 24ч после** — автозакрытие: в чат летит итог, включая список тех, кто слился
- **сбор без дедлайна** — через 2 недели боту приходит «закрой, если не нужен»

Не забиваем, пока бот запущен; каждому одна попытка на ступень — без шкета шторма.

## Установка на сервер (VPS)

```bash
# на своей машине
scp -r skinulis user@vps:~/

# на сервере
ssh user@vps
cd ~/skinulis
BOT_TOKEN=тут-токен python3 bot.py   # long polling — HTTPS для бота не нужен
```

HTTPS нужен только для мини-аппы — поставь Caddy перед сервером (3 строки конфига):

```
твой-домен.ру {
    reverse_proxy localhost:3001
}
```

Чтобы жил постоянно, systemd — `/etc/systemd/system/skinulis.service`:

```ini
[Unit]
Description=Skinulis bot
After=network.target

[Service]
WorkingDirectory=/home/user/skinulis
Environment=BOT_TOKEN=тут-токен
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now skinulis
```

**Docker**:

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY . .
ENV PYTHONUNBUFFERED=1
CMD ["python3", "bot.py"]
```

```bash
docker build -t skinulis . && docker run -d -p 3001:3001 -e BOT_TOKEN=тут skinulis
docker run -v skinulis_data:/app/data ...   # state.json наружу
```

## Что важно знать

- **Деньги через бот не ходят** — реквизиты организатора (`💳 СБП/карта`) показываются
  участникам, они переводят напрямую, в приложении только подтверждают «скинулся».
  Интеграция эталонных платежей в план далее (см. ниже).
- Бот не знает состав чата (ограничение Telegram): участники появляются,
  когда открывают мини-аппу. Кого нет — их дожидает карточка в чате.
- Карточка в чате обновляется сама при каждой оплате/участии/изменении —
  в том числе по удалению (перепостит свежую).
- Время считается по часам сервера.

## Чек-лист релиза

- [ ] `BOT_TOKEN` установлен, `@BotFather` → `/newapp` → https URL готов
- [ ] В чате: `/skor Тест по 1 до завтра` — карточка, кнопка, мини-аппа открылась
- [ ] В мини-аппе: «Я скинулся» — карточка в чате обновилась, счётчик вырос
- [ ] Дедлайн: напоминание неплатившим, итоговое сообщение после закрытия
- [ ] `/list`, `/close`, `/start` отвечают как надо
